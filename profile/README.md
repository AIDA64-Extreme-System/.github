## Four Beats

1. **Name the PC.** Give the AIDA64 Extreme session a short title before you pin parts or sensors.
2. **Pin the live sensors.** Keep current sensor panel values and the system report on the AIDA64 Extreme board and leave unused watches aside.
3. **Check the inventory.** Read the AIDA64 Extreme summary of the stress test view before you treat a reading as final.
4. **Close the loop.** Note which parts are ready so the next AIDA64 Extreme visit does not start by hunting the hardware inventory.

## First Questions

**Does AIDA64 Extreme replace the paper parts list?**  
No. AIDA64 Extreme sits beside the labels, service notes, and files you already use on your own PC.

**Can two power users share one computer?**  
Yes. Each person keeps a separate AIDA64 Extreme profile.

**Will AIDA64 Extreme stay workable on an older office laptop?**  
Yes. AIDA64 Extreme is meant to stay light during a normal inventory session.

**What should a new user try first?**  
One small AIDA64 Extreme system report today on the PC you own, then the same hardware inventory again tomorrow.

## Field Note

AIDA64 Extreme is easier to trust when the report stays smaller than the machine it came from. A named session shows which PC is active, the pins show which sensor panel you will read today, and the closing note tells the next person which system report drives the hardware inventory. That record is short on purpose: not a copy of every part, only the path back to the stress test view that is still open on the reader's own PC.

The same loop fits a student lab machine, a client hardware packet, or a computer shared by two users. Open the last AIDA64 Extreme session, confirm one reading, and leave the sensor panel easier to follow than you found it. Paper sheets stay where they are. AIDA64 Extreme only holds the system report, the hardware inventory, and the handoff.

## One Real Pass

Pick a machine that already has a name: the tower you own, a lab laptop on your desk, or a short test PC. Open it in AIDA64 Extreme, keep only those parts on the board, and read one sensor value you can point to. A pass is done when that value stays tied to the hardware inventory and the unused watches are no longer in the way. AIDA64 Extreme does not need a full rebuild of the system report before it is useful.

If the pass feels crowded, the inventory is too wide. Drop anything that belongs to a different machine and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first part to the last sensor, with the summary still matching the stress test view on that PC.
